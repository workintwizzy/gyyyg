# Снимки версии 1.1

Это реальные снимки Android-приложения на эмуляторе, без подмены модельного ответа.

01 — главная: один записанный подход из семи. 02 — журнал той же тренировки. 03 — следующее упражнение с отдыхом после первого. 04 — помощник до подключения ключа. 05 — главная при 360 dp и шрифте 200%, до начала занятия; содержимое прокручивается, в нижней панели подписана выбранная вкладка.

10 кг × 10 — только проверочная запись эмулятора, не рекомендация начального веса. В APK эти записи отсутствуют. Облачный ответ без личного ключа не проверялся.
