# Тренировки · макеты v2

Четыре согласованных дизайн-макета для следующей версии приложения. Это дизайн-прототип с демонстрационными записями: запросы к модели, сохранение в рабочую базу и миграция текущего APK здесь не выполняются.

## Что изменилось

- **Главная** — центральное «Продолжить», собственная графика ритма и одна настройка «Подстроить». Состав тренировки открывается отдельно. Нет вводных абзацев, ленты упражнений и множества равнозначных кнопок.
- **Журнал** — строки подходов внутри сгруппированных упражнений. Вес, повторения и отметка выполнения читаются по колонкам. Разминка свёрнута. Детали подхода открываются нажатием.
- **Подход** — второй режим той же тренировки: крупный вес и повторения, короткие ±, одна кнопка записи. RIR и оценка техники раскрываются по запросу. Панель отдыха закреплена снизу и показана один раз.
- **ИИ-тренер** — вопрос, одна короткая реплика, точные изменения «было → станет» и явное решение. Причина и состав данных скрыты за раскрытием. Выполненные подходы остаются на месте.

## Подключение в новой версии

Приложение обращается к DeepSeek напрямую по HTTPS. Личный ключ вводится пользователем в настройках телефона и хранится зашифрованно с Android Keystore. В этой концепции нет собственного backend, кода сопряжения, обновления серверной сессии и обязательного аккаунта. В макете настроек показан только пример замаскированного ключа; настоящий ключ в прототип вводить не нужно.

## Общая система

- Шрифт **Golos Text**, с кириллицей: основной текст 500, подписи/кнопки 600, заголовки/крупные числа 700. Веса заданы явно; тонкое начертание не используется. Цифры веса, повторений и таймера табличные.
- Фон `#101518`, поверхности `#1B2328`, текст `#F4F7F5`, вторичный текст `#AEBBC0`, основной акцент `#C9E8B6`.
- Заголовки 22–31 px; основной текст 15–16 px; подписи 12–13 px; активный вес 70 px, повторения 55 px, таймер 39 px. Это размеры макета, для переноса в Compose используются соответствующие sp/dp-токены.
- В основном сценарии видны только данные для следующего действия. Объяснения техники, RIR, настройки оборудования, причины ИИ и сведения о передаче данных раскрываются отдельно.

## Одна сцена на всех экранах

«Всё тело», неделя 5, 17 назначенных рабочих подходов. Первые два подхода жима ногами записаны: 40 кг × 12. Третий ещё не записан. Отдых — 1:32. Это примеры журнала, а не рекомендация начального веса.

ИИ предлагает сократить объём только текущего занятия: жим от груди 3 → 2, верхний блок 3 → 2, подъём гантелей 2 → 1. Итог 17 → 14. Пока предложение не применено, в остальных макетах остаётся 17. В кликабельном прототипе применение обновляет эти числа, отклонение их сохраняет, новый записанный подход делает старое предложение неактуальным.

## Что взято у «Моей волны»

Официальные материалы Яндекса описывают центральный запуск, настройку под ситуацию и интерактивные волны, которые представляют контекстные сценарии. В приложении это интерпретировано как один запуск занятия, собственное кольцо ритма и настройка «время / полегче». Произвольная смена нагрузки через «встряхивание» сюда не переносится: изменения показываются отдельным предложением и подтверждаются.

Графика макета выполнена отдельно, без переноса логотипов и изображений Яндекса.

## Файлы и проверка

- `четыре-экрана.png` — общий лист для просмотра всех экранов вместе.
- `01-главная.png` … `04-тренер.png` — отдельные экраны, рендер ×2.
- `preview.html` — открываемый в браузере кликабельный просмотр.
- `training-v2.html` — редактируемый источник макета для просмотра в чате.
- `assets/` — шрифт и свободные лицензии шрифта и иконок Lucide.
- `preview-checks.json` — результат проверки переходов, записи примерного подхода, актуальности/применения/отклонения предложения и горизонтального переполнения на 360/412 px.

Макеты отрендерены в Chromium/Edge, шрифт загружен из включённого файла. Проверены согласованность 17 → 14, сохранность записанных подходов при применении, отсутствие изменений при отклонении и отсутствие JavaScript-ошибок. Проверки прототипа не являются проверкой нового APK или облачного ответа DeepSeek.
