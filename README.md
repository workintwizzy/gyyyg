# Тренировки · 1.1.8

Личный нативный Android-журнал на русском. Программа, техника, подходы, отдых, история и статистика работают без интернета. По последнему решению владельца приложение обращается к **DeepSeek напрямую**, без собственного backend. Ключ вводится на телефоне; в исходниках и APK его нет.

## Установка и первый запуск

Готовый файл: `outputs/Тренировки-debug.apk`. Устанавливается поверх прежней версии с тем же package `ru.dmitriy.workouts` и сохранением данных, если подпись прежней установки совпадает. Не удаляйте приложение перед обновлением, если хотите сохранить журнал; можно заранее сохранить копию через настройки.

На первом запуске — короткий профиль. Дальше «Сегодня» → «Начать тренировку» в день занятия. В день восстановления можно посмотреть следующий тренировочный день. Рабочий вес выбирается на месте, по росту и массе не рассчитывается. Журнал и крупный подход — два режима одного занятия. Записанные подходы сразу попадают в Room; перезапуск восстанавливает занятие.

## Новый интерфейс

- Раздел «Сегодня»: название дня из программы, текущая неделя, количество упражнений и примерное время по подходам и паузам. В день отдыха — «День восстановления». Центральная объёмная форма плавно движется и пульсирует: яркая мятная в тренировочный день, приглушённая и медленная во время отдыха, спокойная с отметкой после сохранения занятия. Одна большая кнопка: «Начать тренировку», «Продолжить», «Посмотреть результаты» или «Посмотреть следующий день». Просмотр будущего занятия открывает план без запуска тренировки. Форма строится один раз в фоне, дальнейшая анимация использует готовое изображение и локальную ауру. Все размеры и цвета заданы токенами темы.
- Шрифт Golos Text: основной текст 600, заголовки и цифры 700; акцент `#DDFFDF`.
- Плотный журнал подходов и крупный редактор одного подхода; одна панель отдыха.
- Нажатие на заголовок раскрытого упражнения в журнале сворачивает его; повторное нажатие раскрывает снова. На главном экране убраны кнопки «Настроить» и «Упражнения».
- Короткий диалог и нативное сравнение предложенных изменений. Подробности раскрываются по запросу.
- Термины вроде RIR, JSON, CSV и служебных версий не используются в подписях приложения. «В запасе» объясняется обычными словами.

Полные интерактивные канвасы не добавлены согласно условию владельца не делать частичную реализацию. Анализ способов, решение и ограничения — в `CANVAS_ANALYSIS.md`.

## Подключение DeepSeek

1. Откройте настройки → «ИИ-помощник». При необходимости нажмите «Получить ключ DeepSeek».
2. Прочитайте «Что увидит помощник» и разрешите отправку выбранных записей. Передача заметок включается отдельно.
3. Введите личный ключ и нажмите «Сохранить ключ». Сохранение не вызывает платный запрос и не подтверждает действительность ключа.
4. Откройте «Тренер», задайте короткий вопрос и отправьте. Проверка ключа происходит при первом явном запросе.
5. Проверьте поток ответа, «Остановить», сохранение ответа и его чтение после отключения сети. Для изменений выберите вкладку «Изменение» вверху диалога, отправьте запрос, затем просмотрите сравнение.

Фиксированный адрес — `https://api.deepseek.com/chat/completions`, модель — `deepseek-flash`. Актуальность проверена по [официальной документации](https://api-docs.deepseek.com/api/create-chat-completion/). Размышление включено для всех запросов. Его служебные фрагменты не отображаются и не сохраняются как ответ; сохраняется итоговый текст. Поддерживаются потоковый чат, разбор занятия/четырёх недель и структурированные предложения. Ответы с пустым содержимым, обрывом или неподходящими полями отвергаются.

Ключ хранится зашифрованно AES-GCM ключом Android Keystore. Он не сохраняется в Bundle, Room, DataStore, резервных копиях и журналах. Старые серверные сессии при обновлении больше не используются. «Удалить ключ с телефона» очищает локальное подключение; для отзыва самого ключа используйте кабинет DeepSeek.

Сеть принимает только HTTPS с системными сертификатами, включая debug. Автоматических повторов нет; отмена закрывает текущий HTTP-вызов. Один запрос за раз, пауза минимум 3 секунды, максимум 10 запросов в минуту, ожидание до 180 секунд. Это ограничения клиента, не защита счёта от использования ключа на другом устройстве. Запросы оплачиваются со счёта DeepSeek; выдуманная стоимость не показывается. Ключ отсутствовал в среде проверки, настоящий ответ модели не проверен.

Каталог `server/` сохранён как исходники предыдущей архитектуры. Текущий APK не обращается к нему; запуск Node.js, сопряжение и собственный домен не нужны.

## Сборка

Android Studio: открыть этот каталог, установить SDK Platform 37, выбрать Gradle JDK 17+. `compileSdk=37`, `targetSdk=37`, `minSdk=26`. Версии закреплены в Version Catalog, Compose — через BOM. Сохранены Kotlin, Compose/Material 3, Navigation 3, Hilt, Room/KSP, DataStore, Coroutines, serialization и OkHttp.

PowerShell:

```powershell
.\build.ps1
# Если в вашей среде нужен сетевой прокси:
.\build.ps1 -ProxyUrl http://127.0.0.1:10809
# При запущенном эмуляторе или подключённом телефоне:
.\build.ps1 -Tasks connectedDebugAndroidTest
```

`build.ps1` временно использует свободную букву диска через SUBST: это обход ошибки кодировки аргументов JVM в кириллическом пути. Исходники остаются в исходном каталоге. Скрипт освобождает букву после сборки. `local.properties` создаёт Android Studio/скрипт и в git не включается.

Эмулятору достаточно обычного доступа в интернет. Телефон подключается по USB для установки/отладки; перенаправление порта и доступ к компьютеру для ИИ больше не нужны. Установка через Android Studio либо:

```powershell
adb devices
adb install -r .\outputs\Тренировки-debug.apk
```

## Данные и правила

Room — источник фактов, отдельные назначения в занятии не меняются при редактировании будущего плана. Вес хранится целыми граммами; незаполненное значение отличается от нуля. Оборудование учитывается отдельно, гантели — по одной, «мёртвый жук» — на сторону без веса. Разминка и частичные занятия не участвуют в повышении рабочего веса.

`ProgressionEngine` проверяет два сопоставимых полностью завершённых занятия: одинаковые вес/объём/диапазон, все рабочие подходы по верхней границе, запас не меньше двух и хорошая отметка техники. `ContextBuilder` собирает ограниченные выбранные данные; для периода — до 12 завершённых занятий за 28 дней, история чата — до шести реплик. Заметки по умолчанию выключены. Разборы кэшируются по отпечатку записей.

`DeepSeekContract` проверяет полный ответ и кандидата, `ProposalValidator` — упражнения, пределы, правила и актуальность, транзакционное применение — текущую версию ещё раз. Повторное подтверждение не дублирует изменение. Отмена изменения также проверяет, что последующие правки не будут затёрты. Модель не получает прямого доступа к базе.

Схема Room осталась версии 1: обновление дизайна не меняет схему и не удаляет записи. Разрушительный fallback не используется. Настройки читают прежние неизвестные поля без потери совместимости.

Резервная копия — версионированный JSON, включение диалогов отдельно. История также сохраняется таблицей CSV через системный выбор файла. Ключ не экспортируется. Импорт проверяет значения и связи до замены; сначала показывает последствия и требует подтверждения. Повреждённый файл не заменяет базу. Автоматическое резервирование Android выключено; отдельные правила также исключают локальные данные из облачного копирования и переноса между Android-устройствами. См. [официальные правила Android](https://developer.android.com/identity/data/autobackup).

## Отдых и ограничения

Таймер использует монотонное время, сохраняет паузу/срок и учитывает перезагрузку. Перевод часов не меняет остаток. В фоне применяется неточный AlarmManager, поэтому Android может задержать сигнал. Отказ от уведомлений не блокирует занятие. WorkManager и точные будильники для секундного отсчёта не используются.

Итоговые результаты именно этой сборки — в `VERIFICATION.md`. Ранее созданные скриншоты — в `outputs/design-v3/`. Старые макеты и предыдущие отчёты не являются подтверждением нового APK.

## Исправления диалога в 1.1.3

У каждого диалога отдельный черновик и позиция чтения. Новые фрагменты ответа не переносят к концу, если вы читаете старые сообщения. При раскрытии помощника из занятия черновик и место чтения сохраняются. Повторное открытие панели не заменяет ваш вопрос готовой подсказкой. Режимы «Вопрос» и «Изменение» выбираются вкладками вверху диалога; выбор режима сам по себе ничего не отправляет.

История показывает только диалоги с отправленными сообщениями: пустые окна и неотправленные черновики в список не попадают. Для удаления зажмите диалог в списке, выберите «Удалить» во всплывающем меню и подтвердите действие. Короткое нажатие открывает диалог. Удаляются его сообщения и черновик; остальные диалоги, разборы и записи тренировок сохраняются. На экране тренера убраны название провайдера, кнопка пояснения и «К последнему ответу».

Отправка блокируется уже во время подготовки запроса. Поток и сохранённое сообщение используют один идентификатор; карточка предложения связана с ответом конкретного диалога. Очистка чата не переписывает тренировку и не возвращает поздно пришедший ответ. Переходы используют затухание 300 мс без изменения размеров уходящего экрана; нажатия без пружинящего отскока. Системное отключение анимаций учитывается Compose.
