# Сервер «Тренировки»

Node.js 22+ (проверено на 24), TypeScript, Fastify, Zod. Зависимости фиксированы в `pnpm-lock.yaml`. В этой папке нет тестового провайдера; он находится только в `test/`.

```powershell
Set-Location 'C:\Тренировки\server'
pnpm install --frozen-lockfile
Copy-Item .env.example .env
# В .env впишите DEEPSEEK_API_KEY; .env и .state исключены из git.
pnpm run typecheck
pnpm test
pnpm run build
pnpm start
# Во втором PowerShell, тот же каталог и .env:
pnpm run pair
# Экстренно отозвать все устройства и коды:
pnpm run pair -- --revoke-all
```

Если pnpm не установлен, установите актуальный pnpm через Corepack/официальный установщик. Скрипты также запускаются через `npm run`, но для воспроизводимой установки используйте lockfile pnpm. `pnpm dev` запускает TypeScript с перезапуском вручную. `GET /health` доступен без авторизации. При пустом ключе `aiConfigured:false`; запрос ИИ возвращает `503 AI_NOT_CONFIGURED`, выдуманного ответа нет.

Сервер привязывается к `127.0.0.1:8787`. В debug для эмулятора/телефона через USB: `adb reverse tcp:8787 tcp:8787`, адрес в Android `http://127.0.0.1:8787`. Для публичного доступа поставьте reverse proxy с действительным TLS-сертификатом, доменом и проксированием на loopback. Пример Caddy:

```caddy
coach.example.com {
    reverse_proxy 127.0.0.1:8787 {
        flush_interval -1
    }
}
```

В production задайте `ALLOW_LOCAL_HTTP=false` и оставьте `TRUST_PROXY=127.0.0.1` для локального proxy. Сервис должен быть доступен только через этот proxy; не доверяйте произвольным `X-Forwarded-*`. `HOST=127.0.0.1` не открывает порт в LAN. Release Android допускает только HTTPS, проверка сертификата не отключается. Прокси должен пропускать SSE без буферизации и не сохранять тела/Authorization в access/error логах. CORS не включён: приложение нативное.

Одноразовый код — 10 случайных символов, по умолчанию 5 минут. Код хранится SHA-256, одноразовый обмен. Access — 15 минут, refresh — до 30 дней, ротация инвалидирует предыдущие access/refresh. На диске только хеши случайных токенов и минимальные метаданные устройства/сроков. `STATE_FILE` хранится вне публичного web-root с доступом только сервисному пользователю; на Windows настройте ACL каталога для этой учётной записи (POSIX mode Windows не заменяет ACL). Не удаляйте `.state` при обновлении. CLI и сервер должны работать от одной учётной записи с одной конфигурацией. Рассчитано на один процесс сервера; несколько реплик потребуют общей транзакционной auth/idempotency-базы и распределённых лимитов.

Временные ответы и идентификаторы запросов хранятся в памяти максимум 10 минут; завершённые ответы телефона сохраняет Room. Сервер не сохраняет диалоги, журнал, заметки или полный запрос постоянно. Технический лог содержит только requestId, статус, задержку и фактическое usage. Настройте ротацию технических stdout-логов на хосте. Закрытие SSE отменяет fetch, однако уже выполненная работа провайдера может тарифицироваться. Автоповторы по умолчанию отключены; можно включить один для сетевого/5xx сбоя до потока. Невалидные ответы и потоки не повторяются. При падении/рестарте сервера исчезают память лимитов и кэш; клиент не должен автоматически повторять платные действия.

По умолчанию: 6 AI-запросов/минуту на сессию, 10 попыток pairing/10 минут на IP, контекст 64 КиБ, тело 128 КиБ, история 8 сообщений по 3000 символов, ответ до 1800 токенов/12000 символов, timeout 60 секунд. Все параметры ограничены в `config.ts`. Для публичного сервиса дополните per-IP лимиты reverse proxy; настройки сервера не являются защитой от распределённого DDoS.

По официальной документации DeepSeek, проверенной 12.11.2026: актуальный `deepseek-flash` — DeepSeek-V4.1-Flash-1017; доступен `deepseek-v4-pro`. Используются Chat Completions `/chat/completions`, non-thinking mode, SSE и JSON output. Модель задаёт `AI_MODEL`, ключ — только `DEEPSEEK_API_KEY`. JSON output может вернуть пустые пробелы; сервер отклоняет пустой, обрезанный (`finish_reason` не `stop`) и невалидный ответ. Схема Zod проверяется после режима JSON, затем Android проверяет бизнес-правила.

Источники: [модели](https://api-docs.deepseek.com/quick_start/pricing/), [JSON output](https://api-docs.deepseek.com/guides/json_mode/), [thinking mode](https://api-docs.deepseek.com/guides/thinking_mode/), [первый вызов](https://api-docs.deepseek.com/). Контракты: `openapi.yaml`.
