## Дизайн
- Только токены из ui/theme/ (Color.kt, Type.kt, Shape.kt). Хардкод цветов и размеров в экранах запрещён.
- Не использовать дефолтные цвета MaterialTheme, не использовать Roboto.
- Никаких стандартных Card с тенью; поверхности отделять цветом или тонкой обводкой 1dp.
- Все кнопки и инпуты кастомные, не голые Button/OutlinedTextField.
- Анимации: переходы 200-300мс, spring для нажатий.
- Стек: Jetpack Compose.

Оптимизируй процесс разработки без снижения качества кода.

Сохраняй полноценный анализ задачи, продуманную архитектуру, корректную реализацию и необходимые проверки.

Исключай только действительно избыточные операции: повторное чтение неизменённых файлов, дублирующиеся проверки, ненужные полные пересборки и тестирование неподдерживаемых устройств.

Самостоятельно определяй необходимую глубину анализа и тестирования исходя из сложности изменений и риска ошибок.

Для простых изменений используй быстрые точечные проверки. Для сложных изменений, затрагивающих архитектуру, хранение данных, API или несколько компонентов, проводи полноценную проверку.

Не экономь время за счёт качества, надёжности, безопасности или поддерживаемости приложения.

Главный принцип: максимальное качество результата при минимальном количестве бесполезных операций.
